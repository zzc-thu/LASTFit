# Calculation Output

[Case guide](../README.md)

Open [Result_00000002.pvts](Result_00000002.pvts) with its eight VTS pieces
to inspect the representative three-dimensional steady field. It is not a
convergence or regression acceptance dataset. No postprocessed data are supplied.

In the isolated run directory,
the solver writes generated grids to `INIT/`, nonlinear fields and checkpoints
to `RESU/`, and monitoring data to `CheckFiles/`.
