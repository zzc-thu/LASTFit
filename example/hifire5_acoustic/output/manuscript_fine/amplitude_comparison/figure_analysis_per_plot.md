# E-2 / E-3 / E-4 不同扰动幅值影响：逐图分析

## 基本说明

本组图片比较 `E-2`、`E-3` 和 `E-4` 三个周期快声波扰动算例。`E-4` 的 `Config.cfg` 中确认 `epsilon = 5e-4`；`E-2` 和 `E-3` 目录下未找到对应 `Config.cfg`，因此暂按文件夹命名推断为 `epsilon = 5e-2` 和 `epsilon = 5e-3`。

三组算例统一采用保存时间间隔

```text
Delta t_save = 2e-4
```

对应采样频率为

```text
fs = 5000
```

对后半段周期收敛数据进行傅里叶投影，主频统一取

```text
f0 = 666.67
```

其中 `|P_f0|` 表示压力扰动在主频处的谐波幅值，`|P_2f0|/|P_f0|` 用作非线性强弱指标。若扰动响应保持线性，则 `|P_f0|` 应随 `epsilon` 成比例增长，而 `|P_f0|/epsilon` 应基本不变；若大幅值带来非线性，则会出现二倍频增强、归一化响应偏离以及时间波形畸变。

## fundamental_amplitude_scaling.png

该图展示长轴和短轴方向平均主频谐波幅值 `|P_f0|` 随扰动幅值 `epsilon` 的变化，并加入线性参考线。

从结果看，`E-2`、`E-3`、`E-4` 的主频幅值总体随 `epsilon` 增大而增大，说明快声波扰动对壁面压力的一阶响应仍然具有明显的线性缩放特征。长轴方向的 `|P_f0|` 始终高于短轴方向，说明三维椭锥体几何对同一入射扰动存在稳定的周向调制作用。

不过，大幅值 `E-2` 与小幅值算例并非完全落在线性参考线上，说明当扰动幅值提高到 `epsilon = 5e-2` 时，壁面压力响应已经不再是单纯的一阶线性放大，而是开始受到非线性效应影响。

## normalized_fundamental_response.png

该图给出主频谐波幅值的归一化结果 `|P_f0|/epsilon`。这是判断线性或非线性的关键图之一。

如果系统完全线性，则三组算例的 `|P_f0|/epsilon` 应接近同一水平。图中可以看到，长轴方向归一化响应大约在 `3.13-3.37` 之间，短轴方向大约在 `2.43-2.60` 之间，整体仍保持在相近量级，说明主频响应的主体仍是线性的。

但不同幅值之间并不完全重合，尤其长轴与短轴的归一化响应均有一定偏移。这表明随着扰动幅值变化，压力扰动的响应系数也发生改变，存在幅值相关效应。也就是说，大幅值扰动不只是把小幅值结果简单乘以常数，而会改变局部流场响应强度。

## second_harmonic_ratio.png

该图展示二倍频比例 `|P_2f0|/|P_f0|`，是本组分析中最直接体现非线性增强的图片。

`E-3` 中长轴和短轴的二倍频比例约为 `0.025-0.030`，说明中等幅值扰动下高阶谐波较弱，流场响应仍接近线性周期响应。`E-4` 的二倍频比例约为 `0.042`，略高于 `E-3`，这可能与 `E-4` 时间帧数较少、后半段窗口较短造成的频谱泄漏有关，因此不能仅凭这一点判断 `E-4` 更非线性。

真正显著的是 `E-2`：其长轴二倍频比例约为 `0.238`，短轴约为 `0.278`，比 `E-3` 高出约一个数量级。这说明当扰动幅值增大到 `epsilon = 5e-2` 时，周期声波扰动已经诱发明显的非线性波形畸变，并产生强烈的二倍频成分。短轴方向的二倍频比例略高于长轴，说明短轴方向虽然主频幅值较低，但非线性谐波占比反而更强。

## axis_f0_amplitude_profiles.png

该图分为上下两部分：上图为归一化主频幅值 `|P_f0|/epsilon` 沿流向的长短轴分布，下图为未归一化的主频幅值 `|P_f0|` 沿流向分布。

未归一化幅值中，`E-2` 明显最大，`E-3` 次之，`E-4` 最小，符合扰动幅值逐级减小的趋势。归一化后，不同算例的曲线在许多位置仍接近，说明壁面压力扰动在主频上的响应具有可比的线性基础。

同时，长轴曲线普遍高于短轴曲线，尤其在前部扰动较强区域更明显。这说明椭锥体长轴方向更容易放大入射快声波导致的压力扰动。对于大幅值 `E-2`，局部归一化曲线与小幅值算例出现更明显偏离，反映出非线性效应沿流向并非均匀分布，而是在局部区域更突出。

## axis_f0_phase_profiles.png

该图展示主频 `f0` 下长短轴压力扰动相位沿流向的变化。

相位沿流向持续变化，说明主频扰动在壁面附近具有明确的传播特征。长轴与短轴相位曲线不完全重合，表明椭圆截面导致不同周向位置上的扰动传播相位不同。这种相位差不仅来自入射声波本身，也与局部曲率、压力梯度以及边界层结构差异有关。

不同幅值算例之间相位曲线也存在偏移。小幅值下相位变化更接近线性传播；大幅值 `E-2` 的相位分布更容易出现局部偏离，说明非线性不仅改变幅值，也可能改变扰动传播过程中的相位关系。

## late_time_histories_normalized_long_axis.png

该图给出后半段周期收敛窗口内，长轴方向三个典型流向站位 `i = 40`、`i = 81`、`i = 121` 的归一化压力扰动时间历程 `P'/epsilon`。横坐标使用相对时间 `t - t_late,start`，便于比较不同算例在周期窗口内的波形。

在前部站位 `i = 40`，三组算例整体表现为周期振荡，归一化振幅量级接近，说明头部附近主频响应仍以一阶周期波动为主。在中部站位 `i = 81`，波形仍较规则，但不同幅值间相位和振幅已有差别。

最明显的是下游站位 `i = 121`：`E-2` 的归一化波形出现尖峰和非正弦形态，而 `E-3` 与 `E-4` 更接近规则周期振荡。这说明大幅值扰动沿流向传播后会发生更强的非线性畸变，下游区域更容易体现高阶谐波和局部响应增强。

## station_i81_spectra_normalized.png

该图比较 `i = 81` 长轴方向压力扰动频谱，并按 `epsilon` 归一化。

主频附近的谱峰对应周期快声波扰动的主要响应。不同算例在主频附近均有明显能量集中，说明三组扰动都能激发稳定的周期压力响应。归一化后，如果谱线完全重合，则表示频谱结构可由线性缩放解释；实际图中大幅值算例在高阶频率处能量更强，表明大幅值扰动带来了频谱展宽或高阶谐波增强。

因此，该图与 `second_harmonic_ratio.png` 相互印证：`E-2` 不仅主频响应更大，而且相对于主频而言，高阶频率含量也明显增加。

## fundamental_nonlinearity_index.png

该图以最小幅值算例 `E-4` 作为线性参考，比较不同算例的归一化主频响应相对偏离程度。

若各算例完全满足线性缩放，则非线性指数应接近零。图中 `E-3` 和 `E-2` 相对 `E-4` 都存在一定偏离，说明主频响应系数随扰动幅值变化。需要注意的是，该指标只反映主频幅值的偏离，而非全部非线性效应；在周期扰动问题中，二倍频和波形畸变通常更能直接说明非线性。

结合二倍频比例图可以判断：`E-2` 的非线性最强，主要表现为高阶谐波明显增强；`E-3` 仍接近线性响应；`E-4` 是小幅值基准，但由于时间窗较短，二倍频投影可能存在一定频谱泄漏。

## 综合结论

三组算例表明，周期快声波扰动对三维椭锥体壁面压力的主频响应总体随扰动幅值增大而增大，长轴方向始终强于短轴方向，说明椭圆截面对扰动响应具有稳定调制作用。

当扰动幅值较小或中等时，响应以主频为主，归一化幅值基本保持在相近范围，表现出较强线性特征。当扰动幅值增大到 `E-2` 水平时，二倍频比例显著升高，时间历程出现尖峰和非正弦畸变，说明大幅值扰动已经诱发明显非线性变化。该非线性不仅体现在幅值不再完全线性缩放，也体现在高阶谐波生成、相位偏移以及下游波形畸变增强。
