# Calculation Output

[Case guide](../README.md)

Open [Result_00672.pvts](Result_00672.pvts) with its VTS piece
to inspect the representative nonlinear field. It is not a full time history
or regression acceptance dataset. No postprocessed data are supplied.

In the isolated run directory,
the solver writes nonlinear fields and checkpoints to `RESU/`, disturbance
fields to `Pert/`, generated grids to `INIT/`, and monitoring data to `CheckFiles/`.
